# Rose Atelier

Rose Atelier is a boutique floral landing page project created to showcase a romantic, elegant website experience for a modern flower studio.

## Project purpose
This project presents a polished, responsive website for a floral brand built with HTML, CSS, and JavaScript. The design focuses on:
- luxurious rose-inspired styling
- clear information about collections and services
- mobile-friendly responsiveness
- accessible HTML structure and modern visual design

## Website features
- responsive landing page layout
- brand-focused hero section and collection cards
- gallery and service highlights
- contact form interaction
- custom SVG artwork to replace external image dependencies

## How to view the website locally
1. Download or clone the repository.
2. Open the project folder in VS Code or your preferred editor.
3. Either:
   - open `index.html` directly in a browser, or
   - run a local static server such as:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## AI use declaration
AI tools were used during the development of this project to help with:
- website layout planning and copywriting
- generating a polished design direction and brand tone
- creating custom vector-based artwork for the floral visuals
- refining CSS and JavaScript interactions for a more responsive experience

The project itself was reviewed and adapted manually to fit the assignment requirements and ensure the final result is consistent and complete.

## Files included
- `index.html` – page structure and content
- `styles.css` – styling and responsive layout
- `script.js` – reveal animation and contact form behavior
- `assets/` – custom SVG artwork and favicon
